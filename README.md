 DRIVE-EASY
 Car Booking System

A modern car rental platform built with React and Vite that allows users to browse available cars, book vehicles, and manage their reservations through a simple and user-friendly interface.

Key Features:

Browse and explore cars.

Book cars with pickup and return dates.

Calculate estimated rental costs.

View and manage bookings.

Cancel reservations.

Save booking data in browser local storage.

Technologies: React, Vite, JavaScript, CSS, React Router.

Note: This project currently uses frontend-only storage for testing.
